ใต้ฝากระโปรง

ทำงานยังไง

  • Vision เดียวจบ — Gemini 3 Flash อ่านรูป → ดึง merchant, เลขที่/วันที่, items[] เป็น JSON ในครั้งเดียว
  • Catalog matching — LLM ส่งแค่ product_code, ระบบ map ชื่อ display จาก catalog → (code, name) ไม่มีทางเพี้ยน
  • จับร้านด้วย fuzzy — rapidfuzz จับชื่อร้านที่สะกดต่างเล็กน้อย โดยมี Store master เป็น source of truth
  • Auto-attach Visit — จับคู่ (ร้าน, เดือน) อัตโนมัติ + เตือนทันทีเมื่อวันที่/ร้านไม่ตรง
  • เรียนรู้ต่อเนื่อง — product aliases + catalog gap events สะสมขึ้นจากการแก้ของคน

ความปลอดภัยข้อมูล

ข้อมูลอยู่กับเรา ควบคุมได้

  • ข้อมูลเก็บฝั่งเรา — ภาพต้นฉบับ + ฐานข้อมูลอยู่ในระบบของเรา เข้าถึงผ่าน admin
  • กันซ้ำ/เพี้ยน — file hash ตรวจไฟล์ซ้ำตั้งแต่อัปโหลด
  • ส่ง LLM แค่ภาพ — vision-only ไม่ส่ง/ไม่เก็บราคาหรือข้อมูลการเงิน
  • Production ใช้ Vertex AI (GCP) — ข้อมูลอยู่ใน project/region ของเราเอง (เลือก region ใกล้ไทยได้) + DPA กับ Google Cloud · demo นี้ใช้ OpenRouter เพื่อพัฒนาเร็ว · ถัดไป: มาส์ก PII + RBAC
อ้างอิง: Google Cloud — Vertex AI Data Governance · "won't use your data to train or fine-tune any AI/ML models without your permission" (ผูกพันตาม Cloud Data Processing Addendum)
